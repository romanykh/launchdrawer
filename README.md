# Launchdrawer
Gnome extension to add launchpad-like app drawer inspired by Mac OS launchpad

This extension written by AI, I simply don't understand JavaScript :) (for now)

Launchdrawer can be summoned by "pinch" touchpad gesture or by keybind "Super+L" (you must disable lockscreen keybind first in settings)

> Instalation

Download the launchdrawer.zip from "Releases" and go to terminal:
```
cd Downloads (or any other folder where you downloaded the file)
gnome-extensions install launchdrawer.zip
```
Then relogin to gnome session and have fun!

Also, you can customize the size, color or opacity in launchpadView.js and stylesheet.css
